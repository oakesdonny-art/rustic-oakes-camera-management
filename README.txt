Rustic Oakes Camera Management — Installable PWA

This package is ready to be hosted as a Progressive Web App.

Important:
- Android/Chrome will only offer "Install app" when the files are served from HTTPS (or localhost).
- Opening index.html directly from Downloads / local storage will NOT trigger PWA installation.
- Once hosted, open the HTTPS address in Chrome. The page will show an Install button when Chrome allows installation.
- After installation it opens in a standalone app window and works offline after the first load.

- manifest.webmanifest
- service-worker.js
